Exploring BC Air Quality Data

The hourly PM2.5 observations wer obtained from the National Air Pollution Surveillance (NAPS) Program (Environment and Climate Change Canada 2026).

Inspect Air Quality Datasets

Code 
pm25_2023 <- read_csv("data/raw/airquality/2023/data_2023.csv")
stations_2023 <- read_csv("data/raw/airquality/2023/stations_2023.csv")
n_distinct(pm25_2023$NAPS_ID) # monitoring stations

data_2023.csv:
Data has 481800 hourly PM2.5 observations across BC for 2023 (8 columns). Each row shows one PM2.5 concentration measurement, one monitoring station, one date, start, and end time.
* Important: NAPS_ID -> can connect to stations_2023.csv

stations_2023.csv:
Observations are recorded by 55 monitoring stations.
Useful fields out of 43:

  • NAPS_ID
  • Station_Name
  • City
  • Latitude: will be used to calculate distances from nearby fires
  • Longitude: same as latitude
  • Elevation_m
  • Site_Type
  • Urbanization
  • Land_Use
  • AQMS_Airzone

Research

Particulate Matter (PM) is a complex mix of solids and aerosols. PM2.5 describes the fine particulate matter that are 2.5 microns or less in diameter (PM2.5).

Ambient Air Quality Standard in BC:
24-Hour Average: 25 µg/m^3
Annual: 8 µg/m^3 (Government of British Columbia 2026)

4. Missing Data by Station

Code 
pm25_2023_joined |>
  group_by(NAPS_ID, Station_Name) |>
  summarise(
    observations = n(),
    missing = sum(is.na(Concentration)),

  ) |>
  arrange(desc(percent_missing))

Quite high for few ie. Powell River… has 40.8% missing, and the total missing is 5.77%. A station like Powell River might distort station specific analyses.

Using a heat map, check whether missing is a random hourly equipment gaps throughout year (less concerning) or an entire month worth of data is missing (concerning).

Figure 1: Missing PM2.5 Measurements by Station and Month
Stations have missingness in subsequent months. Thus, it is not just random hourly equipment gaps. For example, Powell River Station has a high concentration of missing values from August to December.

How to determine whether a fire was relevant to PM2.5?

REP_DATE: Date associated with fire
ATTK_DATE: Fire suppression start date
OUT_DATE: Fire out date

REP_DATE == PM2.5 date would not work because fire can still be burning on other days and make the air quality bad. Plus, wind blows and the PM2.5 cover areas in varying times.

Calculating the duration of the fire in days by finding the difference between reported dates of fire and the date the fire was put out.

Finding the PM2.5 data between REP_DATE and OUT_DATE is very crude and potentially treat a fire equally as day 2 as day 92.

Using REP_DATE only

REP_DATE has no missing values making it more reliable.

This uses a recent-fire variable (to be created). It is going to check previous 7/14/30 days of air-quality stations and find any large fires within different perimeters in those days.

This is not looking for currently “active” fires like was told before.

Conclusion

Air Quality Data

  • NAPS provides complete hourly station grids for each year
  • PM2.5 measurement missingness ranges from 4.84% to 7.23% across 2022–2024
  • Missingness varies substantially between monitoring stations and many appear in subsequent months
  • Extreme PM2.5 values occur in sustained episodes

Large Fire Data

  • 382 BC large vegetation fire records available from 2022-2024
  • Fire size is strongly right-skewed
  • Following provides non-usable information for BC 2022-2024 records: PRESECRIBED, ATTK_DATE, FIRE_TYPE
  • OUT_DATE contains one inconsistent record that was found
  • Use recent-fire windows based on Fire_Date to connect to PM2.5 date

Analysis Design

One monitoring station on one day with columns being:

  • Date
  • NAPS_ID
  • Station_Name
  • Latitude
  • Longitude
  • mean_pm25
  • max_pm25
  • hours_observed
  • recent_fire_count_100km
  • recent_fire_count_250km
  • recent_fire_area_250km
  • nearest_recent_fire_km
  • Year
  • Month

These are the questions I have formed and will be answering:

  • How did daily PM2.5 differ between 2022-2024?
  • Can we classify a station day as High-PM2.5 vs. Normal?
  • Can recent large-fire proximity/activity help predict daily PM2.5?
  • Do distinct types of station-days apppear naturally?

# How to determine whether a fire was relevant to PM2.5?

REP_DATE: Date associated with fire  
ATTK_DATE: Fire suppression start date  
OUT_DATE: Fire out date  

REP_DATE == PM2.5 date would not work because fire can still be burning on other days and make the air quality bad. Plus, wind blows and the PM2.5 cover areas in varying times.

# Conclusion

## Air Quality Data

- NAPS provides complete hourly station grids for each year
- PM2.5 measurement missingness ranges from 4.84% to 7.23% across 2022–2024
- Missingness varies substantially between monitoring stations and many appear in subsequent months
- Extreme PM2.5 values occur in sustained episodes

## Large Fire Data

- 382 BC large vegetation fire records available from 2022-2024
- Fire size is strongly right-skewed
- Following provides non-usable information for BC 2022-2024 records: PRESECRIBED, ATTK_DATE, FIRE_TYPE
- OUT_DATE contains one inconsistent record that was found
- Use recent-fire windows based on `Fire_Date` to connect to PM2.5 date
