Question 1 - KNN Regression

Among station days with a recently reported large fire, can fire proximity and recent fire activity be used to predict daily mean PM2.5?

Predictors

  • nearest_fire_km_14d: how close was the nearest recent fire?
  • fire_count_100km_7d: how much very nearby and very recent fires were there?
  • fire_count_250km_14d: how much broader nearby fire activity was there?

This covers proximity, very local + very recent activities, and broader fire activities.

In other words it is essentially asking: Which historical station days had a similar combination of nearest fire distance, nearby recent fire count, and broader recent fire count, and what PM2.5 did those days experience?

Will regression work better

Classification threw away a lot of information making data analysis limited. However, regression retains the numerical data as is. Although this does not guarantee a good model, it seems to be better-fit for regression.

Problem that might rise

Our target is extremely right-skewed and that may lead to a very large RMSE.

Plus, the predictors are still zero-heavy and the nearest fire in km within recent 14 days have many missing values. Due to lack of data, the regression might become unreliable.

Analysis

MAE = 4.42
This means the predictions differ from the actual daily mean PM2.5 by about 4.42 µg/m^3 on average.

RMSE = 10.5
Being much larger than MAE suggests that there are some very large predictions errors. This can be found in the Predicted vs Actual plot where most observations are clustered near 0-30 but it doesn’t predict for the extreme PM2.5 values of 100+.

R^2 = 0.156
The model explains about 15.6% of the variation in daily mean PM2.5. So proximity and recent fire counts did contain some useful information but most PM2.5 variation remains unexplained.

Thus, the regression model captured some relationship between recent wildfire conditions and daily PM2.5 but it has limitations. It particularly tends to greatly underpredict the extreme PM2.5 events.

KNN vs. Linear Regression

Comparison of KNN and linear regression test performance
Model RMSE MAE R_squared
KNN Regression 10.499 4.422 0.156
Linear Regression 10.284 4.821 0.106

The KNN and linear regression models show very similarly limited predictive performance. Linear regression had a slightly lower RMSE (10.3 µg/m^3; KNN 10.5 µg/m^3), while KNN had a lower MAE (4.42 µg/m^3; linear 4.82 µg/m^3) and a higher R^2 (0.156; linear 0.106). This indicates that KNN captured more variation and differ less from the actual value compared to linear, suggesting that wildfire and PM2.5 relationship is not strictly linear.

Nevertheless, both models were barely able to explain the overall variation. Therefore, the fire proximity and fire coutns alone are insufficient for accurate PM2.5 prediction.

    linear_reg_metrics |> filter(.metric == "mae") |> pull(.estimate)
  ),
  R_squared = c(
    knn_reg_metrics |> filter(.metric == "rsq") |> pull(.estimate),
    linear_reg_metrics |> filter(.metric == "rsq") |> pull(.estimate)

The KNN and linear regression models show very similarly limited predictive performance. Linear regression had a slightly lower RMSE (10.3 µg/m^3; KNN 10.5 µg/m^3), while KNN had a lower MAE (4.42 µg/m^3; linear 4.82 µg/m^3) and a higher R^2 (0.156; linear 0.106). This indicates that KNN captured more variation and differ less from the actual value compared to linear, suggesting that wildfire and PM2.5 relationship is not strictly linear.

Nevertheless, both models were barely able to explain the overall variation. Therefore, the fire proximity and fire coutns alone are insufficient for accurate PM2.5 prediction.
